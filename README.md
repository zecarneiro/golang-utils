# Golang Utils

To use this library on your project, you need to run commands on root of your project:

1. `go get github.com/zecarneiro/golangutils` or add this project as a lib folder
2. To use `ui` you will need external app on linux, like:
  - zenity
  - notify-send: libnotify-bin(Ubuntu/Debian/Linux Mint), libnotify(Fedora/RHEL/CentOS/Arch Linux/Manjaro) and libnotify-tools(openSUSE)
  - kdialog(for KDE)
